# Beyond Cards – Animated Luxury Wedding Invitations

A complete, production-quality, visually elegant royal animated wedding invitation website platform built with React, Vite, TypeScript, Tailwind CSS, Framer Motion, and GSAP.

## Features

- **Dual Invitation Support**:
  - **Hafiz & Aisha** (Default live invitation)
  - **Anzar & Fathima** (Preserved royal edition)
- **Centralized Wedding Configuration**:
  - Independent couple configurations in `src/config/`
  - Dynamic runtime switching with reactive URL state (`?couple=hafiz-aisha`)
- **Royal Wedding Aesthetic & Animations**:
  - Royal palace hero background with multi-layer parallax and swaying royal lanterns
  - Authentic live countdown timer with digit reel spring animations
  - Overlapping polaroid composition in "Our Story"
  - Horizontal swipeable photo gallery with interactive lightbox modal
  - Burgundy hanging celebration banner with custom notched "Add to Calendar" button (.ics & Google Calendar)
  - Palace illustration with directions integration
  - Vintage gold oval floral photo frame
  - Interactive RSVP modal with celebration confetti and WhatsApp notification
  - Royal burgundy closing card with Arabic Dua (*Barakallahu lakuma wa baraka alaikuma wa jama'a bainakuma fee khair*)
- **Beyond Cards Luxury Branding**:
  - Bespoke vector monogram emblem and luxury typography
  - Minimalist royal footer with back-to-top navigation

## Tech Stack

- **Framework**: React 18 with Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion & GSAP
- **Icons**: Lucide React
- **Effects**: Canvas Confetti, Web Audio API

## Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
